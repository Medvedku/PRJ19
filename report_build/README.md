# Report Build & Typst Compilation (`report_build/`)

The `report_build` directory contains the templates, branding assets, document definitions, and compiled PDF artifacts for engineering monitoring reports generated by `reports_assembly.py`.

---

## 🔑 Security & Credentials Note

> [!IMPORTANT]
> The compiled PDF reports included in this directory are pre-built and ready for instant viewing. Re-building or regenerating new report batches via `reports_assembly.py` **will work only with `DB_PASS` (or `DP_PASS`)** configured in `.env` for database decryption. The report framework is fully functional and **ready to be reviewed**.

---

## 📁 Directory Structure

```
report_build/
├── template.typ                 # Core Typst document layout & page formatting template
├── Metrotech01.svg              # Primary corporate logo asset
├── sign.svg                     # Digital author signature asset
├── document.typ                 # Master/latest Typst document configuration
├── 2025_10/ ... 2026_08/        # Monthly report directories (contain generated .typ sources)
└── PRJ19_report_MM_YYYY.pdf    # Final compiled engineering PDF reports
```

---

## 📄 Typst Publishing System (`template.typ`)

Reports are typeset using **Typst**, a high-performance markup document compiler.

### Template Specifications:
* **Page Layout**: A4 Landscape (`297mm x 210mm`) with `1.5cm` margins.
* **Branding**: Header displays project title (`M2717 - Slovenská Ľupča`), report month/year subtitle, author attribution, and corporate logo (`Metrotech01.svg`).
* **Visual Presentation**: Embedded fullpage SVG charts generated by `plotter/functions.py` with figure captions formatted according to Slovak engineering conventions.
* **Footer**: Automatic page numbering (`1 / N`).

---

## 📑 Generated Reports Batch

The output PDF documents (`PRJ19_report_MM_YYYY.pdf`) cover monthly observation periods:
* **2025**: October (`10`), November (`11`), December (`12`)
* **2026**: January (`01`) through August (`08`)

---

## 🛠️ Direct Compilation Example

To manually recompile a `.typ` document file to PDF using the CLI:

```bash
typst compile report_build/2026_03/document_03_2026.typ report_build/PRJ19_report_03_2026.pdf --root /
```
